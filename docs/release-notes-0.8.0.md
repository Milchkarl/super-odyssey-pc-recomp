## Fixed / new

- **Glow around the sun, clouds and bright objects (#102)**: it came out as stacked blocks instead of a smooth fade, because the game's glare effect read the wrong blur levels. In our tests it now matches the emulator.
- **Bloom quality: Off** (Graphics): removes the game's glow entirely (#123).
- **Motion blur: On / Off** (Graphics): the blur while the camera turns (#123).
- **Shadow distance** (Graphics): Switch / 2x / 4x, how far shadows reach (#123).
- **Snapshot Mode at the full frame rate** (an option, #123).
- **Shake on any button or key, a spin throw key and a screenshot key** (Controls, #62, #73, #123). Screenshots go to the `screenshots` folder next to the game's log.
- **Mouse**: smoothing (#123), and the camera can stay where you put it instead of re-centering behind Mario (#88). The mouse wheel zooms the map (#82).
- **First-person view** can start facing the way Mario looks (Controls, off by default, #118).
- **amiibo** (Controls): pick a virtual figure; when the game asks for one, it gets that figure (#48).
- **Start page** shows the installed game's version, 1.0.0 or 1.4.1 (#110).
- **Pause menu** at 16:10 and 4:3 with Narrow picture view set to Full width: Mario and Cappy in their place (#112).
- **Quit to Desktop** on the settings page before the game did nothing (#133).
