lost while rebinding, interpolation on - confirmed twice), #65 (shadow flicker under blocks with interpolation on).
Native frame rates (Performance > Frame rate 72-240) do the same job without interpolation. **Owner decision:** remove
120 FPS interpolation for v1.0, or hide it behind an "experimental" switch with a crash warning.
