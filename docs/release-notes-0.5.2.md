## Fixed / new

- **Crash fixes**: fixed a crash that could happen after playing for a long time.
- **Better CPU performance**: part of the game's own code now runs as native PC code, so unpacking the game's files when you arrive in a kingdom or load an area takes much less CPU time. Fewer drops right after loading.
- **Better game performance**: smoother frame rate on CPUs with fewer cores, such as the Steam Deck, and fewer shader stutters after updating.

## Updating

Shaders are prepared once more after this update (a few minutes; about 6 on a Steam Deck). The game code is not rebuilt.

Windows: download the zip below and extract it over your current folder (or use **Updates** in the menu). Linux / Steam Deck: download the AppImage below, or use **Updates** in the menu. Your game files, saves and settings stay.
