## Fixed / new

- **New settings menu**: tabs across the top, a live picture of the game while you change settings, and a cleaner full-screen look. The start screen matches it.
- **Gyro aiming through binoculars** now turns the right way (#53).
- **16:10 and narrower screens**: a new option, Display > Narrow picture view, shows the whole picture instead of cropping the sides (#112).
- **Setup** now says when its bundled compiler is damaged, instead of only "The game code didn't build" (#121).
- **Crash reports** are now written when the game is started from a launcher (#115).
- **Draw distance** now notes that Very high can halve the frame rate in busy kingdoms.
- New players start with VSync off and the performance overlay at the bottom left.

## Still to fix

- Out of graphics memory on 8 GB laptops with integrated graphics (#120, #99).
- Frame rates above 60 aren't fully smooth yet.
